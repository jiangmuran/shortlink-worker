API 文档

REST API 基地址为当前域名，所有接口位于 /api/v1，使用 API 密钥认证。

认证

在控制台「API 密钥」页面创建密钥（形如 sk_…），请求时通过 Header 携带：

Authorization: Bearer sk_xxxxxxxxxxxxxxxxxxxxxxxx

所有响应为 JSON：{"ok": true, "data": …} 或 {"ok": false, "error": {"code": "…", "message": "…"}}。接口已开启 CORS，可从任意来源调用。

权限范围

Scope说明
links:read读取短链列表、详情与点击统计
links:write创建、修改、删除短链
logs:read读取访问记录（受账户权限限制）
domains:read读取可用域名列表

端点

GET/api/v1/me

查看密钥归属的用户与权限。

curl -H "Authorization: Bearer $KEY" https://your-domain.com/api/v1/me
GET/api/v1/domainsdomains:read

列出密钥可用的短链域名。

POST/api/v1/linkslinks:write

创建短链。body 字段：

{
  "url": "https://example.com/long/path",   // 必填，http(s)
  "domain": "s.example.com",                // 可选，缺省用第一个可用域名（也可传 id）
  "code": "my-link",                        // 可选，缺省随机生成（1-64 位 [A-Za-z0-9_-]）
  "length": 6,                              // 随机后缀长度 4-10，默认 6
  "mode": "direct",                         // direct | page | confirm
  "style": {                                // 中转页/确认页自定义
    "animation": "orbit",                   // orbit | progress | pulse | fade（page 模式）
    "duration": 1200,                       // 停留毫秒数 500-5000（page 模式）
    "title": "即将跳转", "desc": "", "button": "继续访问",
    "color": "#0a84ff"
  },
  "note": "备注",                            // 可选
  "expires_at": "2027-01-01T00:00:00Z"      // 可选，ISO 时间或毫秒时间戳
}
curl -X POST https://your-domain.com/api/v1/links \
  -H "Authorization: Bearer $KEY" \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com","code":"demo"}'

# → {"ok":true,"data":{"id":1,"short_url":"https://s.example.com/demo", ...}}
GET/api/v1/linkslinks:read

列出短链。查询参数：page、per（1-100，默认 20）、domain（hostname 或 id）。

GET/api/v1/links/:idlinks:read

获取单条短链详情。

PATCH/api/v1/links/:idlinks:write

修改短链。可更新 url、note、mode、style、enabled、expires_at（传 null 取消过期）。

curl -X PATCH https://your-domain.com/api/v1/links/1 \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/updated"}'
DELETE/api/v1/links/:idlinks:write

删除短链及其访问记录。

GET/api/v1/links/:id/statslinks:read

点击统计：累计 / 今日 / 7 日 / 30 日，附带最近 10 条访问（IP、地区、UA）。

错误码

HTTPcode含义
400invalid_target目标链接无效（必须是 http/https）
400invalid_code后缀格式无效或为保留字
401unauthorized缺少或错误的 API 密钥
403insufficient_scope密钥缺少所需权限范围
403forbidden账户无相应权限（域名范围 / 功能开关）
403quota_exceeded超出账户短链数量配额
404not_found资源不存在
409code_taken后缀已被占用
